# 📘 Instrucciones de Despliegue

## ¡Tu página web está lista para ser publicada! 🎉

He creado todo lo necesario para que tu página web sea visible en Internet. Ahora solo necesitas seguir estos pasos simples:

## 🚀 Pasos para Publicar tu Página

### Paso 1: Mergear a la rama principal

Esta Pull Request contiene todos los archivos necesarios para tu sitio web. Para publicarlo:

1. **Revisa los cambios** en esta PR (Pull Request)
2. **Aprueba y mergea** esta PR a la rama `main`
3. GitHub Actions automáticamente desplegará tu sitio

### Paso 2: Habilitar GitHub Pages (si no está habilitado)

Si es la primera vez que usas GitHub Pages en este repositorio:

1. Ve a **Settings** (Configuración) de tu repositorio
2. En el menú lateral, busca **Pages**
3. En **Source** (Fuente), selecciona **GitHub Actions**
4. Guarda los cambios

### Paso 3: Acceder a tu página

Una vez que se complete el despliegue (toma 1-2 minutos), tu página estará disponible en:

```
https://edgar-emo.github.io/pagina_proyecto_metodologias/
```

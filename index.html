Bienvenido a Nuestro Proyecto

Este es un proyecto dedicado al estudio y aplicación de metodologías de desarrollo.

Sobre el Proyecto

Este proyecto fue creado como parte de un curso de metodologías de desarrollo de software. Aquí exploraremos diferentes enfoques y prácticas para crear mejores productos de software.

📚 Aprendizaje

Estudiamos las mejores prácticas y metodologías actuales

🚀 Aplicación

Metodologías Estudiadas

  • Scrum: Framework ágil para gestión de proyectos
  • Kanban: Sistema visual para gestión de flujo de trabajo
  • Extreme Programming (XP): Metodología enfocada en la excelencia técnica
  • DevOps: Prácticas que combinan desarrollo y operaciones

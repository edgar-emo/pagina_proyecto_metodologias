# Página Proyecto Metodologías

Este es un proyecto web dedicado al estudio y aplicación de metodologías de desarrollo de software.

## 🌐 Ver la Página Web

La página está publicada en GitHub Pages y se puede acceder en:

**https://edgar-emo.github.io/pagina_proyecto_metodologias/**

## 📋 Descripción

Esta página web presenta información sobre:
- Diferentes metodologías de desarrollo de software
- Prácticas ágiles y frameworks
- Colaboración y aprendizaje en equipo

## 🚀 Despliegue

La página se despliega automáticamente usando GitHub Actions cuando se hacen cambios en la rama `main`. El workflow está configurado en `.github/workflows/static.yml`.

### Para actualizar la página:

1. Realiza cambios en `index.html` o `styles.css`
2. Haz commit y push a la rama `main`
3. GitHub Actions automáticamente desplegará los cambios
4. La página estará disponible en pocos minutos

## 📁 Estructura del Proyecto

```
.
├── index.html           # Página principal
├── styles.css           # Estilos CSS
├── .github/
│   └── workflows/
│       └── static.yml   # Workflow de GitHub Actions

```
